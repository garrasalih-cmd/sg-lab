# 📋 سكرتيري: الدليل الكامل (المراحل 1–5)

🌐 **رابط التطبيق:** https://sekretiri.netlify.app

تطبيق PWA عربي يعمل كسكرتير شخصي. يحفظ المهام على الهاتف أولًا (يعمل بلا إنترنت)، ويزامنها مع Supabase وGoogle Calendar عند الاتصال.

---

## 🧱 البنية

```
 الهاتف (PWA)                         Supabase (مشروع sekretiri)              Google
┌────────────────────────┐        ┌──────────────────────────────┐
│ الشاشات: المهام · الصباح │        │ قاعدة البيانات + RLS            │
│ الخطة · التركيز · المساء │ ◄────► │  tasks · settings · push_subs  │
│ أسبوعي · الإعدادات       │ مزامنة │                              │
│                        │        │ دالة الخادم sek (Edge Function)│ ◄──► Calendar API
│ IndexedDB (أوفلاين)     │        │  • ربط Google (OAuth)          │
│ Service Worker ◄─ Push ─┼────────┤  • مزامنة ثنائية مع التقويم     │
└────────────────────────┘        │  • إشعارات الصباح/المساء/التذكير │
                                  │ pg_cron: كل 5 دقائق ⇒ sek      │
                                  └──────────────────────────────┘
```

## ✅ ما هو جاهز في Supabase (أنجزتُه)
- المشروع `sekretiri` (فرانكفورت) + كل الجداول + قواعد الأمان RLS
- دالة الخادم `sek` منشورة، والمؤقّت يعمل كل 5 دقائق
- مفاتيح الإشعارات (VAPID): العام في `config.js`، والخاص في الخادم فقط

### النشر على Netlify
1. **netlify.com** ← سجّل الدخول بـ GitHub ← **Add new site** ← **Import an existing project** ← **GitHub** ← `sg-lab`
2. **Branch:** `claude/secretairy-pwa-app-aabrud` · **Base directory:** `secretary` · **Build command:** فارغ
3. **Deploy**. كل تحديث أرفعه يُنشر تلقائيًا.
4. ⚠️ Manage ← **Who can see it** ← اجعله **Public**، وإلا لن يعمل التثبيت ولا الإشعارات ولا المشاركة.

## 🚧 بصراحة: حدود PWA والبدائل

| القيد | البديل المستخدم |
|---|---|
| لا يستمع لـ«صباح الخير» والهاتف مقفل | إشعار صباحي (6:30 افتراضيًا) يفتح وضع الصباح مباشرة |
| الإملاء الصوتي يحتاج إنترنت | 🎤 في لوحة المفاتيح، أو الكتابة |
| تذكير بوقت دقيق والتطبيق مغلق | تنبيهات Google Calendar (دقيقة جدًا)، أو Push من الخادم (بدقة ±5 دقائق) |
| مؤقّت التركيز إذا أغلقت التطبيق | يكمل بدقة عند فتحه، لكن صوت النهاية قد يتأخر. أبقِ الشاشة مفتوحة (التطبيق يمنع انطفاءها) |
| مزامنة التقويم ليست لحظية | فوري من التطبيق إلى التقويم، وكل 15 دقيقة بالعكس |
| الصوت العربي للقراءة | الإعدادات ← الإدارة العامة ← تحويل النص إلى كلام ← Google ← ثبّت العربية |
| Samsung قد يوقف الإشعارات لتوفير البطارية | الإعدادات ← التطبيقات ← Chrome ← البطارية ← **غير مقيّد** |

## 🧯 مشاكل شائعة

| المشكلة | الحل |
|---|---|
| 🎤 «اسمح للميكروفون» | Chrome ← ⋮ ← الإعدادات ← إعدادات المواقع ← الميكروفون |
| «سكرتيري» لا يظهر في المشاركة | ثبّت التطبيق أولًا ثم أعد تشغيل الهاتف |
| النقطة على ⚙️ حمراء | افتح ⚙️ لترى سبب الخطأ وأرسله لي |
| لا تصل الإشعارات | تأكد من تسجيل الدخول، ثم 🔔 فعّل، ثم «جرّب إشعارًا»، ثم البطارية (أعلاه) |
| التحديث الجديد لا يظهر | أغلق التطبيق وافتحه مرتين |

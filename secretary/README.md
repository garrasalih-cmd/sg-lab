# 📋 سكرتيري: دليل التشغيل (المرحلة 1)

تطبيق PWA عربي يعمل كسكرتير شخصي. يحفظ المهام على الهاتف أولًا (يعمل بلا إنترنت)، ويزامنها مع Supabase عند الاتصال.

---

## 🗺️ خريطة الملفات

| الملف | ماذا يفعل |
|---|---|
| `index.html` | الصفحة الوحيدة، وفيها الشاشات الثلاث (الرئيسية، المشاركة، الإعدادات) |
| `css/style.css` | التصميم الداكن، خط Cairo، أزرار كبيرة |
| `js/app.js` | ربط الأزرار والشاشات |
| `js/store.js` | منطق المهام: إضافة، إنهاء، حذف |
| `js/db.js` | التخزين في الهاتف (IndexedDB) |
| `js/sync.js` | المزامنة مع Supabase وتسجيل الدخول |
| `js/voice.js` | الإملاء الصوتي بالعربية |
| `js/util.js` | الفئات، التواريخ، تخمين الفئة من الكلمات |
| `sw.js` | Service Worker: العمل بلا إنترنت |
| `manifest.webmanifest` | التثبيت على الهاتف + استقبال المشاركة من واتساب |
| `config.js` | ⚙️ عنوان Supabase ومفتاحه (تعدّله أنت) |
| `supabase/schema.sql` | إنشاء جدول المهام وقواعد الأمان |
| `netlify.toml` | إعدادات النشر على Netlify |

## الخطوة 1: إنشاء مشروع Supabase (5 دقائق)

1. ادخل إلى **supabase.com**، ثم **Dashboard**.
2. اضغط **New project**:
   - **Organization**: `SG Lab`
   - **Name**: `sekretiri`
   - **Database Password**: اضغط **Generate** واحفظها في مكان آمن (لن نحتاجها في التطبيق)
   - **Region**: `Central EU (Frankfurt)`، وهي الأقرب لإسرائيل
   - اضغط **Create new project** وانتظر دقيقتين حتى يجهز.
3. من القائمة الجانبية افتح **SQL Editor** ثم **New query**.
4. انسخ محتوى الملف `supabase/schema.sql` كاملًا والصقه، ثم اضغط **Run**.
   يجب أن تظهر رسالة `Success. No rows returned`.
5. افتح **Project Settings** (⚙️) ثم **API Keys**، وانسخ:
   - **Project URL**، ويشبه `https://abcd1234.supabase.co`
   - **Publishable key**، ويبدأ بـ `sb_publishable_` (أو مفتاح `anon` في تبويب Legacy)
   - ⚠️ **لا تنسخ** مفتاح `secret` أو `service_role` أبدًا.
6. افتح `config.js` وضع القيمتين بين علامات الاقتباس.

> 💡 أو اطلب مني في المحادثة: «أنشئ المشروع»، ووافق على طلب الإذن، فأنفّذ الخطوات 2 إلى 6 بنفسي.

### إعداد تسجيل الدخول (بعد النشر في الخطوة 2)
في Supabase افتح **Authentication** ثم **URL Configuration**:
- **Site URL**: عنوان تطبيقك على Netlify، مثل `https://sekretiri.netlify.app`
- **Redirect URLs**: أضف العنوان نفسه.

هكذا يفتح رابط تأكيد البريد تطبيقك بدل صفحة خطأ.

## الخطوة 2: النشر المجاني على Netlify (ربط تلقائي بـ GitHub)

**لماذا Netlify مع GitHub؟** كل تعديل أرفعه إلى GitHub يُنشر تلقائيًا خلال دقيقة، فلا ترفع ملفات بيدك أبدًا.

1. ادخل إلى **netlify.com**، ثم **Sign up**، واختر **GitHub** (الدخول بحساب GitHub نفسه).
2. اضغط **Add new site** ثم **Import an existing project** ثم **GitHub**.
3. اسمح لـ Netlify بالوصول، واختر المستودع **sg-lab**.
4. املأ الإعدادات هكذا:

   | الحقل | القيمة |
   |---|---|
   | Branch to deploy | `claude/secretairy-pwa-app-aabrud` (أو `main` بعد الدمج) |
   | Base directory | `secretary` |
   | Build command | اتركه **فارغًا** |
   | Publish directory | `secretary` (يظهر تلقائيًا) |

5. اضغط **Deploy**. بعد دقيقة يظهر رابط مثل `https://random-name-123.netlify.app`.
6. (اختياري) لاسم أجمل: **Site configuration**، ثم **Change site name**، واكتب `sekretiri`.

> ✅ هذا لا يغيّر شيئًا في موقع المختبر على GitHub Pages.

## الخطوة 3: التثبيت على Galaxy A56

> ⚠️ استخدم **Chrome** وليس **Samsung Internet**، لأن الإملاء الصوتي والمشاركة يعملان في Chrome.

1. افتح رابط التطبيق في **Chrome**.
2. اضغط **⋮** (أعلى اليمين)، ثم **إضافة إلى الشاشة الرئيسية** ثم **تثبيت**.
   (أو من داخل التطبيق: ⚙️، ثم «ثبّت سكرتيري على الشاشة الرئيسية»)
3. تظهر أيقونة 📋 «سكرتيري» على شاشتك، ويفتح كتطبيق كامل بلا شريط عنوان.
4. اضغط مطوّلًا على الأيقونة لتجد اختصار **«مهمة جديدة»**.

## 🧪 كيف تختبر المرحلة 1 على هاتفك

| الاختبار | الخطوات | النتيجة المتوقعة |
|---|---|---|
| إضافة بالكتابة | اكتب «تصحيح امتحان الصف العاشر» | تُختار فئة 🏫 مدرسة تلقائيًا. اضغط «أضف» |
| موعد | اختر «اليوم» ثم ساعة 14:00 | تظهر «اليوم 14:00» تحت المهمة |
| إملاء صوتي | اضغط 🎤 وقل «زيارة ماما يوم الجمعة» | يظهر النص في الحقل، وتُختار 👨‍👩‍👧 عائلة |
| مشاركة من واتساب | اضغط مطوّلًا على رسالة، ثم ⋮، ثم **مشاركة**، ثم **سكرتيري** | تفتح شاشة «وصلتك مهمة». اضغط الفئة فتُحفظ |
| إنهاء وتراجع | اضغط ✓ على مهمة، ثم «تراجع» | تختفي ثم تعود |
| بلا إنترنت | فعّل وضع الطيران وافتح التطبيق وأضف مهمة | يعمل كالمعتاد |
| المزامنة | ⚙️ ثم «حساب جديد» ثم أكّد البريد ثم «دخول» | النقطة الخضراء على ⚙️ تعني «متزامن ✅» |
| عودة الإنترنت | أضف مهمة في وضع الطيران ثم أطفئه | تصبح النقطة خضراء خلال ثوانٍ |

> ℹ️ **سكرتيري** يظهر في قائمة المشاركة فقط **بعد تثبيته**.
> ℹ️ التحديثات الجديدة تظهر عادة في **الفتح الثاني** للتطبيق (لأنه يعرض النسخة المحفوظة أولًا ليفتح بسرعة).

## 🧯 مشاكل شائعة

| المشكلة | الحل |
|---|---|
| 🎤 «اسمح للميكروفون» | Chrome ثم ⋮ ثم الإعدادات ثم إعدادات المواقع ثم الميكروفون، واسمح للموقع |
| الإملاء لا يفهم لهجتي | ⚙️ ثم «لهجة الإملاء»، وجرّب لهجة أخرى |
| «سكرتيري» لا يظهر في المشاركة | ثبّت التطبيق أولًا (الخطوة 3) ثم أعد تشغيل الهاتف |
| النقطة حمراء ⚠️ | ⚙️ تعرض سبب الخطأ. تأكد من `config.js` ومن تشغيل `schema.sql` |
| رابط تأكيد البريد يفتح صفحة خطأ | الحساب تأكّد رغم ذلك. ارجع للتطبيق واضغط «دخول»، ثم أصلح Site URL (أعلاه) |
